This project is a simple Python-based Caesar Cipher program developed as part of a Cybersecurity training project.

The Caesar Cipher is one of the earliest and most well-known encryption techniques. It works by shifting letters in the alphabet by a fixed number of positions.

## 🔍 How the Encryption Works

The Caesar Cipher shifts each letter by a specific number of positions in the alphabet.

### Encryption Formula

E(x) = (x + n) % 26

### Decryption Formula

D(x) = (x - n) % 26

Where:

* `x` = current letter position
* `n` = shift value
