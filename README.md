## 📅 Week 1 — Password Security Fundamentals

### 🎯 Focus

Understanding password security and validation techniques.

### 🔐 Project — Password Strength Checker

Built a Python program that evaluates password strength based on common security standards.

### ✅ Features

* Minimum length validation
* Uppercase letter detection
* Number detection
* Symbol detection
* Password strength classification:

  * Weak
  * Medium
  * Strong

### 🧠 Key Learnings

* IPO Model (Input → Process → Output)
* Conditional logic and validation
* Importance of password policies
* Basic secure coding principles

📂 Project Folder:

```bash
password-strength-checker/
```

## 📅 Week 2 — Basic Encryption & Decryption

### 🎯 Focus

Understanding encryption fundamentals and data confidentiality.

### 🔐 Project — Caesar Cipher Encryption Tool

Built a Python-based Caesar Cipher program capable of encrypting and decrypting user messages.

### ✅ Features

* Encrypt plaintext messages
* Decrypt encrypted messages
* User-defined shift value
* Supports uppercase and lowercase letters
* Preserves spaces and punctuation

### 🧠 Key Learnings

* Encryption & decryption concepts
* ASCII character manipulation
* Modular arithmetic (`% 26`)
* Data confidentiality fundamentals
* Algorithmic problem-solving

📂 Project Folder:

```bash
caesar-cipher-encryption/
```
